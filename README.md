## ✨ Features

- ✅ Clean, dark-themed responsive design
- ✅ Toggleable sections: Home, Projects, About, Contact
- ✅ Project thumbnails that open full project in new tab
- ✅ Social media buttons (LinkedIn, GitHub, Instagram)
- ✅ Contact form
- ✅ Animated typing text on the homepage
- ✅ Profile photo and location background
